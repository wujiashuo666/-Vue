# 我的系统

基于 Spring Boot + Vue 3 的前后端分离管理系统。

## 技术栈
- 后端：Spring Boot、MyBatis、Spring Security、Redis
- 前端：Vue 3、Element Plus、Vite

## 启动方式
1. 启动 MySQL，创建数据库 `vhr`，导入 `vhr.sql`
2. 启动 Redis
3. 运行 `VhrApplication.java`
4. 前端 `cd vuehr && npm install && npm run dev`
5. 访问 http://localhost:8080，默认账号 admin / 123
